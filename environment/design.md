# Recursive Adaptive Dynamics (RAD)
# Environment Design

## Purpose

This document defines the minimal environment model used to test recursive adaptive dynamics.

The environment exists to generate:

\[
\Omega_t
\]

constraint-bearing information produced through consequences.

The environment is not designed to test intelligence.

It is designed to test whether adaptive mechanism-space trajectories diverge under different causal update rules.

---

# 1. Environment State

The environment is represented as:

\[
E_t=(R_t,C_t,N_t)
\]

where:

| Symbol | Meaning |
|-|-|
| \(R_t\) | hidden environmental regime |
| \(C_t\) | active constraints |
| \(N_t\) | novelty structure |

---

# 2. Hidden Regime

The environment contains a latent rule:

\[
R_t
\]

The agent does not directly observe:

\[
R_t
\]

Instead, the agent receives consequences:

\[
\Omega_t
\]

generated by interaction.

---

# 3. Constraint State

The environment imposes constraints:

\[
C_t
\]

Examples:

- resource limitations
- changing objectives
- altered reward structures
- restricted actions
- delayed consequences

The constraint state determines which mechanisms remain viable.

---

# 4. Consequence Signal

The environment generates:

\[
\boxed{
\Omega_t=f(X_t,E_t)
}
\]

where:

- \(X_t\) is system state
- \(E_t\) is environment state

\(\Omega_t\) contains consequence information available to the agent.

It may include:

- success/failure
- delayed outcomes
- environmental feedback
- resource changes
- constraint violations

---

# 5. Regime Dynamics

The environment changes over time:

\[
R_1\rightarrow R_2\rightarrow R_3...
\]

The purpose is to create:

\[
d(R_t,R_{t+1})>0
\]

between phases.

---

# 6. Environmental Phases

## Phase 1 — Stabilization

Goal:

Allow mechanisms to specialize.

Properties:

- stable constraints
- repeated exposure
- predictable consequences

Expected:

\[
P(t)\uparrow
\]

for most agents.

---

## Phase 2 — Transition

Goal:

Introduce mismatch.

Properties:

- previous successful mechanisms lose effectiveness
- consequences change
- alternative mechanisms become valuable

Expected:

Divergence begins.

---

## Phase 3 — Novelty

Goal:

Test future adaptive capacity.

Properties:

- unfamiliar constraints
- new optimal strategies
- altered mechanism requirements

Primary measurement phase.

---

# 7. Minimal Task Example

The environment contains hidden mappings.

\[
R_t
\]

defines which mapping is currently valid.

Example:

\[
R_1:A\rightarrow B
\]

Later:

\[
R_2:C\rightarrow D
\]

A mechanism optimized for \(R_1\) may fail under \(R_2\).

---

# 8. Mechanism Interaction

Each mechanism receives environmental consequences:

\[
G_i(X_t,E_t)
\]

The result affects:

- performance
- history
- accessibility
- viability

---

# 9. Novelty Generator

Novelty controls environmental change:

\[
N_t
\]

Possible parameters:

## Magnitude

\[
\Delta_E=d(E_t,E_{t+1})
\]

How different is the new environment?

---

## Frequency

\[
f_N
\]

How often changes occur?

---

## Predictability

\[
p_N
\]

Whether future changes can be inferred.

---

# 10. Environment Requirements

A valid RAD environment should:

## Preserve early comparability

Before disruption:

\[
P_A\approx P_B
\]

---

## Reward specialization

Stable periods should allow optimization.

---

## Require adaptation

Later phases should make old strategies insufficient.

---

## Avoid direct intelligence measurement

The environment should test:

\[
\text{adaptive-space preservation}
\]

not:

\[
\text{problem-solving ability}
\]

---
